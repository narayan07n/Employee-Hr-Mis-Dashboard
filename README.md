##Employee HR/MIS Dashboard
## Project Overview
This project is an interactive Employee HR/MIS Dashboard developed using Microsoft Excel.
The dashboard is designed to help HR teams and management analyze employee workforce data, salary trends, performance, experience, departments, and city-wise employee distribution.

## Tools Used
- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Slicers
- Excel Formulas
- Data Cleaning
- Data Analysis
- Dashboard Design

## Dataset
The dataset contains 2,000 employee records with information related to:
- Employee details
- Department
- City
- Salary
- Experience
- Performance
- Other HR-related attributes

## Dashboard KPIs
The dashboard includes:
- Total Employees: 2,000
- Average Salary: ₹40.7K
- Average Experience: 4.8 Years
- Excellent Performers: 373

## Key Dashboard Analysis
### 1. Department-wise Average Salary
The dashboard compares average salary across departments.

IT has the highest average salary among the departments, while Customer Support has the lowest average salary.

### 2. Performance Distribution
Employee performance is divided into:
- Average
- Excellent
- Good
- Needs Improvement

This helps HR understand the overall employee performance structure.

### 3. Experience vs Average Salary
The dashboard analyzes how average salary changes with employee experience.

The analysis shows an increasing salary trend as experience increases.

### 4. Department-wise Employees
Employee headcount is analyzed across departments to identify workforce distribution.

### 5. City-wise Employees
The dashboard provides employee distribution across cities including:
- Bengaluru
- Delhi
- Gurugram
- Hyderabad
- Lucknow
- Mumbai
- Noida
- Pune

## Interactive Features
The dashboard includes interactive slicers for:
- City
- Performance
- Department

Users can filter the dashboard and analyze specific employee groups.

## Business Use Case
This dashboard can help HR and management with:
- Workforce analysis
- Salary analysis
- Employee performance monitoring
- Department-wise headcount planning
- Location-wise workforce analysis
- HR reporting and decision-making

## Project Objective
The main objective of this project is to transform raw employee data into an interactive and easy-to-understand HR/MIS dashboard for management reporting.
